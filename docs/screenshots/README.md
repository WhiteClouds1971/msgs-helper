## 二、规格与命名

- **格式**：`.png`
- **尺寸**：手机竖屏，**当前这一套统一为 `742 × 1320`**（约 `371 × 660` 逻辑尺寸的 2x 导出）；新增同系列截图请保持同样的比例与尺寸，单张尽量 < 1MB
- **命名**：全小写英文、连字符分词、不带版本号与日期，例：`home.png`、`skills.png`
- **一张图只截一个状态**：不要把详情页和主页拼在一张图里

## 三、怎么截

**方式 A：Chrome 设备工具栏（推荐）**

1. 本地跑起来：`npm run dev`，浏览器打开 `http://localhost:9456`
2. `F12` → `Cmd + Shift + M` 打开设备工具栏 → 选 `iPhone 14 Pro Max` / `iPhone 15 Pro Max`
3. 设备工具栏右上角 `⋮` → **Capture screenshot**（只截当前视口）
   - ⚠️ **不要用 Capture full size screenshot**：`#app` 是 `overflow: hidden` 的固定高度壳，整页截图会截到壳外、版面失真
4. 设备工具栏里的 DPR 选 2x 或 3x，导出即高清

**方式 B：真机**

手机与本机同局域网 → 打开 `http://<你电脑的局域网 IP>:9456`（dev 服务已开 `host: 0.0.0.0`）→ 用系统截图，注意裁掉状态栏与浏览器地址栏，或直接用「全屏网页截图」类工具。

**方式 C：把生产包丢到手机上**

`npm run build` 之后把 `dist/` 放到任意静态服务器，手机访问同一地址截图。

## 四、拍摄注意事项

- **等启动画面过去再截**：打开瞬间有一屏「受命于天 既寿永昌」的启动画面，等它淡出、卡片/正文都加载完再拍
- **别把教学蒙层拍进去**（除非这张图就是拍教学）：首次进入主页或菜单页会自动弹出导览高亮，等它关掉或者先访问一次再回来拍
- **主题统一**：前四张用浅色主题，`dark.png` 再切深色；主题在玉玺长按 → 控制台 → 「切换主题」
- **截图前先访问一次页面**，让「最近访问置顶」把最好看的那张卡排到最前面，同时消耗掉首次教学
- 手机竖屏拍照，横屏或带桌面端宽屏留白的图放进 README 会显得很空
