# 村规

> 本页内容为**占位样稿**，用来验证 `MdViewer` 组件；正式村规直接改写本文件即可。
> 文件位置：`src/assets/md/cun-gui.md`

## 一、开局准备

### 1.1 议规

开局前先逐条过一遍本规，**有异议当场提出**，开牌后不再追溯。约定优于规则，本桌议定的条目覆盖默认条款。

### 1.2 选将

1. 主公先亮明身份，从主公将池中选将
2. 其余玩家按座次依次抽取，抽到的武将不得私下调换
3. 全员确认武将技能文本无歧义后再发牌

### 1.3 发牌

- 每人初始手牌 **4 张**
- 主公首轮多摸 1 张
- 手牌数量当场公开确认，之后不再复核

## 二、回合流程

| 阶段 | 处理 | 备注 |
| --- | --- | --- |
| 准备阶段 | 结算回合开始时的技能 | 判定区效果先于摸牌 |
| 判定阶段 | 由上至下逐张结算判定牌 | 改判需在亮牌后立刻声明 |
| 摸牌阶段 | 摸 2 张 | 被跳过则本阶段不执行 |
| 出牌阶段 | 自由使用牌 | 每张【杀】限一次 |
| 弃牌阶段 | 手牌弃至体力值 | 体力上限即手牌上限 |

## 三、判定与结算

### 3.1 判定顺序

牌堆顶翻开一张牌即为判定牌，结算完毕后置入弃牌堆。多名角色的技能同时触发时，按**当前回合人开始逆时针**顺序结算。

### 3.2 争议处理

- 口说无凭的争议，以牌面文字为准
- 牌面确有歧义时，由主公裁定，裁定结果对本局有效
- 已翻开的牌不得回退

## 四、出局与胜负

- 角色体力降至 0 且无【桃】可救，即出局
- 出局玩家翻开身份牌，手牌与装备全部置入弃牌堆
- 胜负判定：

  - 主公与忠臣：反贼与内奸全部出局
  - 反贼：主公出局
  - 内奸：最后一名存活

## 五、补充约定

- [x] 手机静音，非紧急不接电话
- [x] 出牌前先声明，再亮牌
- [ ] 允许旁观者提醒规则（待议）

## 六、附：常用判定说明

```text
判定牌 = 牌堆顶第一张
改判时机 = 判定牌亮明后、结算前
改判限制 = 每张判定牌最多改判一次（本桌约定）
```
