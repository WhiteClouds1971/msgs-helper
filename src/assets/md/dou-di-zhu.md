# 斗地主

一主二农的三国杀变体玩法：由一名地主对抗两名农民。

## 一、豆子的发放与结算

每局游戏开始前，向每名玩家发放 15 枚豆子。当任意一名玩家的豆子输尽时，本局即告结束，并进行结算；结算完毕后，重新向每名玩家发放 15 枚豆子。

## 二、身份牌与叫价

游戏开始前，随机向各玩家发放身份牌。随后自身份牌为地主的玩家起，依次进行一轮叫价。

- 若有人叫价至 3 倍，该玩家即刻成为地主，叫价就此结束。
- 否则，由叫价最高者成为地主。

## 三、奖池与豆子归属

地主确定后，双方按本局叫价倍数（记为 X）向奖池投入豆子：

| 身份 | 投入奖池的豆子 |
| --- | --- |
| 地主 | 2X 枚 |
| 每名农民 | X 枚 |

游戏结束后，奖池内的全部豆子按胜负归属：

| 结果 | 豆子归属 |
| --- | --- |
| 地主胜利 | 地主独得奖池内的全部豆子 |
| 农民胜利 | 两名农民平分奖池内的全部豆子 |

## 四、选将框

| 身份 | 选将框数量 |
| --- | --- |
| 地主 | 5 个 |
| 农民 | 各 3 个 |

## 五、换将卡与手气卡

本模式支持使用换将卡与手气卡：

- 换将卡：弃置任意张武将卡，然后摸取等量张武将卡。
- 手气卡：弃置任意张手牌，然后摸取等量张手牌。

## 六、身份映射与模式专属技能

- 首轮开始时，地主视为主公，农民视为反贼。
- 部分特殊武将在斗地主模式中，须使用模式专属的武将技能。
