# 规则&村规

> 依据《三国杀官方规则集 3.0》整理，结合本桌《村规》。括号内为举例说明时机的武将/装备。

**重要原则1**：结算中当前回合角色优先 —— 同一时机多名角色可选择响应或发动技能时，从当前回合角色开始按逆时针依次决定；一名角色在同一时机有多个技能，由其自行决定顺序。

**重要原则2**：
- 当技能的说明、基本牌/锦囊牌的说明与游戏通则或用语操作规范冲突时，按如下优先级遵循：技能的说明＞基本牌/锦囊牌的说明＞游戏通则或用语操作规范。
- 当两个技能的效果/操作冲突时，表示否定意思的效果/操作优先级高于表示肯定意思的效果/操作。

**重要原则3**：插入结算顺序原则：所有结算都是事件在合理的时机插入发生后所进行的处理过程，因此凡是插入发生的事件都优先结算，即后发生的事件先结算。 例如：角色因受到伤害而进入濒死状态，先结算插入的濒死事件，濒死结算完毕再继续结算伤害事件。

## 一、身份模式

| 身份 | 胜利条件 |
| --- | --- |
| 主公 | 消灭所有反贼与内奸 |
| 忠臣 | 与主公相同 |
| 反贼 | 主公死亡 |
| 内奸 | 成为最后的生还者 |

| 人数 | 主公 | 忠臣 | 反贼 | 内奸 |
| --- | --- | --- | --- | --- |
| 5 | 1 | 1 | 2 | 1 |
| 6 | 1 | 1 | 3 | 1 |
| 7 | 1 | 2 | 3 | 1 |
| 8 | 1 | 2 | 4 | 1 |

身份牌共 10 张（主 1、忠 3、反 4、内 2），配置可按本桌约定调整。

**开局**：随机抽身份牌（主公亮明，其余扣置）→ 选将 → 每人 4 张起始手牌 → 人数 ≥ 5 时主公体力上限 +1 → 由主公起逆时针进行回合。

**奖惩**：杀死反贼者立即摸三张牌（凶手即使是反贼）；主公杀死忠臣，立即弃置所有手牌与装备。

**结束**：主公死亡 —— 内奸独存则内奸胜，否则反贼胜；反贼与内奸尽亡则主公忠臣胜。满足条件立即终止结算；牌堆与弃牌堆的牌不足时平局。

**死亡**：体力值扣至 0 进入濒死，未被救回即死亡；死亡后弃置其所有牌与判定区的牌，武将牌上/旁的牌置入弃牌堆，再亮出身份牌。

## 二、游戏流程

**游戏开始时** → 每轮开始 → 一号位回合 → 二号位回合 → …… → **每轮结束** →（回到"每轮开始"，循环往复）

### 游戏开始时（一局一次）

神将/多势力武将先确定势力 → 亮武将牌 → 分发起始手牌（每人 4 张）→ 触发"游戏开始时"技能（【狂暴①】）。

### 每轮开始

由一号位起，按逆时针，每名角色依次进行一个回合。

### 每名玩家的回合

**回合开始** → 准备阶段 → 判定阶段 → 摸牌阶段 → 出牌阶段 → 弃牌阶段 → 结束阶段 → **回合结束**

| 阶段 | 要点 |
| --- | --- |
| 准备阶段 | 通常无事；【洛神】【观星】 |
| 判定阶段 | 从最后置入判定区的延时锦囊起逐张结算 |
| 摸牌阶段 | 摸两张；【突袭】【英姿】 |
| 出牌阶段 | 用牌主阶段，仅**空闲时间点**可行动 |
| 弃牌阶段 | 手牌数 > 体力值则弃至体力值；【固政】 |
| 结束阶段 | 通常无事；【闭月】【据守】 |

- 回合：一名玩家从回合开始到回合结束的完整流程；轮：所有玩家各走一个回合。
- "回合内"仅指自己的回合，"每回合"指所有角色的回合；"XX 阶段"仅指自己的该阶段，"每阶段"指所有角色的每阶段。
- 上家/下家：左右手边的角色，仅两人时互为上下家。
- 翻面：将武将牌由正/背面朝上翻转至背/正面朝上的操作（【放逐】【悲歌】）；背面朝上的角色于回合开始时翻正，并跳过此回合。
- 跳过阶段/回合：其中任何细节都不执行，本回合也不能再跳同一阶段（刘禅【乐不思蜀】后不能跳过出牌阶段发动【放权】）。

### 每轮结束

一轮走完直接进入下一轮。

## 三、机制详解

### 区域与归属

| 区域 | 说明 |
| --- | --- |
| 牌堆 | 扣置，摸牌来源 |
| 额外牌堆 | 线下专属牌堆；牌堆里的牌进入弃牌堆后移出游戏，重新洗入额外牌堆；其中的牌没有顺序，且非无限供应 |
| 弃牌堆 | 正面朝上，牌用毕的去处 |
| 处理区 | 结算中转（判定牌、拼点牌、被弃置的牌等） |
| 场上 | 所有角色的装备区与判定区 |
| 角色区域 | 手牌区 + 装备区（武器、防具、+1坐骑、-1坐骑、宝物各一）+ 判定区 |

- 手牌：自己手中的牌、扣置、仅自己可见。
- 牌 = 手牌 + 装备区里的牌，这两者属于该角色自己（手牌属于自己、自己装备区的牌也属于自己）；判定牌不属于任何人，判定区里的牌也不属于该角色（故【寒冰剑】不能弃判定区的牌）。
- 武将牌上/旁的牌移出游戏、不为任何人所有（邓艾"田"）：默认对其他玩家不可见；需其他玩家辅助核验操作合法性时（如核对点数、花色、数量），则对其他玩家可见。
- 废除区域：装备区里的各个装备栏（武器、防具、坐骑、宝物）与判定区彼此独立，只有在**未废除**的状态下才能被废除 —— 同一区域不能被废除两次；已废除的区域不能再放置对应的牌（装备牌／延时锦囊）。

### 距离与范围

- 距离 = 两人间顺/逆时针的最短路径，死亡角色不参与计算。
- 一名角色与其他角色之间的距离最短为 1
- 自己与自己的距离永远为 0；自己不在自己的攻击范围内。
- 攻击范围 = 武器标识值（无武器为 1，【青釭剑】为 2）；目标在攻击范围内才能对其用【杀】。
- 【+1坐骑】令他人到你 +1，【-1坐骑】令你到他人 −1；

距离方向的读法（技能常用文本）：

- "距离为 1"：你到其他人的距离
- "与你距离为 1"：其他人到你的距离
- "其距离你"：其他人到你的距离
- "你距离其"：你到其他人的距离

### 数值与牌面

| 名词 | 含义                                     |
| --- |----------------------------------------|
| 体力上限 | 武将牌上的阴阳鱼数                              |
| 体力值 | 实际体力                                   |
| 手牌上限 | = 体力值，仅在弃牌阶段起作用                        |
| 已损失体力 | 体力上限 − 体力值                             |
| 差 | 两个数值相减所得结果的**绝对值**（如"手牌数与体力值之差"） |
| 伤害值基数 | 牌/技能中"造成 X 点伤害"的 X                     |
| 点数 | A=1、J=11、Q=12、K=13；超过 K 视为 K，小于 A 视为 A |
| 花色 | 红桃、方块为红；黑桃、梅花为黑（【仁王盾】只挡黑【杀】）           |
| 势力 | 魏蜀吴群晋；神、魔势力入场时须改为魏蜀吴群晋之一               |

- （全场）...数：这些数值在计算时都不考虑已经死亡的角色。
- （数值）最大／小：允许多名角色并列最大／小，其中每一名都是该数值最大／小的。
- **唯一**最大／小：要求无并列 —— 若有多名角色并列最大／小，就不存在"唯一最大／小"的角色，以之为条件的效果无从执行。

### 使用与结算

牌的使用结算流程：

| 时机 | 要点 / 技能                              |
| --- |--------------------------------------|
| 选择目标时 / 使用时 | 声明牌名、选目标、展示实体牌；【武圣】【集智】 |
| 指定目标时 / 成为目标时 | 目标可变可增；【流离】【享乐】                      |
| 指定目标后 / 成为目标后 | 目标锁定；【铁骑】【青釭剑】【贞烈】                   |
| 使用结算开始时 | 查有效性（【仁王盾】【藤甲①】【毅重】），无效即终止           |
| 生效前 | 响应：【闪】挡【杀】、【无懈可击】挡锦囊；被抵消则跳过生效        |``
| 生效时 / 生效后 | 执行效果；延时锦囊先判定                         |
| 使用结算结束后 | 非装备牌的实体牌进弃牌堆                         |

操作牌的流程：多数操作令一张牌自其来源区域（牌堆、手牌等）置入处理区，待结算完毕后置入弃牌堆；摸牌、交给、置于牌堆顶或武将牌上等操作则直接移入目标区域，不经处理区。

以下各项均为对牌的操作。

- 使用与打出是两种**独立**的动作：
  - 使用 = 主动令牌产生效果：使用【杀】指定目标、使用【闪】响应【杀】、使用【桃】回复体力。
  - 打出 = 被动响应：打出【杀】响应【南蛮入侵】【决斗】，打出【闪】响应【万箭齐发】。
  - 同样是【闪】：响应【杀】是使用，响应【万箭齐发】是打出。
- **出杀次数**（这块是三国杀经典的屎山代码，目前没有合理严谨的解释，面杀中以本条村规为准）
  > 核心规则：自己的每个出牌阶段空闲时间点只能使用一张杀。（空闲时间点 指 **自由发动技能和使用手牌的时间段**）
  - **不计入次数的【杀】**（【龙吟】）：使用后不占用次数，本阶段仍可继续使用【杀】；但若本阶段此前已使用过计入次数的【杀】，则本张杀不可使用。
  - **无次数限制的【杀】**（【诸葛连弩】）：全称为"不计入次数且无次数限制"，即其不受出杀次数的影响，也不影响出杀的次数。
  - **技能中无特殊说明的杀**：这是歧义最多的地方，按照定义 武将、装备等技能发动期间属于**非空闲时间点**，因此在技能结算期间使用的杀均无次数限制，但这十分不合理，因此增加如下约束
    - 如果 技能是在自己的出牌阶段发动，以**使用杀为目的**，则在技能结算后，这些杀计入次数限制；且若无出杀次数，则无法发动此技能。（如【透髓】和【缚豕】等。但是注意如界刘备的【仁德】印的杀无次数限制，因为【仁德】印的是基本牌）
- 多目标：结算前所有目标逐个走完同一时机，结算中按行动顺序逐名结算。
- 延时锦囊：判定区已有同名牌者不是合法目标；
- 判定：亮出牌堆顶的一张牌作为"判定牌"，其花色、点数、牌名即此次判定的结果。
- 拼点：各扣置一张手牌后同时亮出，点数大者赢、相同则都没赢。参与拼点的角色都必须有手牌，任一方没有手牌则不能进行拼点。
- 移动：改变一张牌所在的区域。若移动的牌是装备牌，默认须目标装备区里的相应空位为空，方能移入。
- 弃置：把某角色区域里的牌置入处理区再入弃牌堆；"令 B 弃置"由 B 选牌弃置，"A 弃置 B 的牌"由 A 选牌弃置。
  - 置入弃牌堆 ≠ 弃置，后者才触发弃置类技能。这也是两个独立的操作
  - "弃置…任意张牌"中的"任意数量"表示此数量可以为 0，即可以一张都不弃置。
  - 若有应弃置之牌因效果（【鸡肋】【共损】等）不能弃置，以致无法完成弃置，须展示所有手牌，然后进入"弃牌阶段结束时"。
  - 弃置须由角色执行：角色可以主动弃置牌，牌只能被弃置。
- 重铸：将牌置入弃牌堆后摸等量张牌。
- 获得 / 失去：牌进你的手牌区即获得，从你拥有的区域（手牌、装备）移出即失去（【屯田】【枭姬】）。
- 获得 ／ 选择：**获取**默认是随机获得 —— 如"获得其一张手牌"即从其手牌中随机取一张；**选择**则是在指定范围内挑出符合条件的一张再获得 —— 如"从额外牌堆选择一张智囊牌获得"。规则集口径：牌对操作者不可见的区域（手牌）随机获得，可见的区域（装备区、判定区）可任意选择。
- 观看 / 展示 / 亮出：仅自己可见且不移动／全场可见、看完放回来源区域／全场可见且不放回来源区域（判定牌）。
- 交给 / 分配：把非对方拥有的牌放入其手牌
  - 交给：对象须为其他角色，不能给自己（【仁德】）。
  - 分配：可以给自己（【遗计】"交给一名角色"）。
- 视为 / 当：把牌当另一张牌用。
  - "视为使用"的牌均为虚拟牌，虚拟牌均无颜色、花色、点数，称为无色。
  - 单张牌转化：花色、点数、颜色均与原牌相同，仅牌名改变。
  - 多张牌转化：没有花色和点数；颜色取所当之牌的公共颜色 —— 各牌颜色一致才带该颜色，否则该虚拟牌为无色牌。
  - 转化至少要有一张牌作原牌：如"将所有手牌当…使用"一类效果，若没有满足条件的牌，视为未执行此操作（无手牌时不能发动【奇策】）。
  - 一张牌不能被连续转化两次：转化只决定这张牌在某一次使用或打出中充当哪个牌名，该次声明的牌名一经确定，便不能再对它叠加另一次转化（【武圣】将红色牌当【杀】使用后，此牌不能再被【龙胆】当【闪】、被【朱雀羽扇】当火【杀】）。
  - "视为"不是转化，而是直接改写牌名：一张红桃牌受【武神】影响视为【杀】后，其牌面信息即为【杀】，可再被【龙胆】当【闪】使用或打出。

### 伤害与生死

伤害结算时机：

| 时机 | 要点 / 技能 |
| --- | --- |
| 结算开始前 / 开始时 | 【绝情】改为失去体力；【狂风】火伤 +1、【大雾】防非雷伤 |
| 造成伤害时 | 【裸衣】【麒麟弓】【寒冰剑】【古锭刀】 |
| 受到伤害时 | 【天香】【名士】【藤甲②】【白银狮子①】 |
| 造成伤害后 | 【狂骨】【破军】 |
| 受到伤害后 | 【奸雄】【反馈】【刚烈】【遗计】【悲歌】 |
| 结算结束时 / 结束后 | 【天香】摸牌、横置者重置；【酒诗②】、触发连环 |

- 六要素：渠道、属性、来源、承受者、伤害值、是否连环伤害。来源 = 造成伤害的角色（其已死亡则无来源）；渠道 = 造成伤害的牌/技能。
- 伤害减为 0 = 防止全部伤害，视为未造成/未受到过伤害；
- "受到伤害后"指一次伤害，X 点伤害可令"每 1 点伤害后"类技能发动 X 次。
- "受到伤害后"排在濒死结算之后：伤害结算中若"受到伤害时"未能防止伤害，须进行扣减体力结算；体力被扣至 0 者立即进行濒死结算，两者均结算完毕后，才推进到"造成伤害后""受到伤害后"。
  - 故角色若死于该次濒死结算，【奸雄】【遗计】【刚烈】等"受到伤害后"技能不再触发；被救回则照常触发。
- 无效／抵消／取消：无效 = 终止对该目标的结算但仍可被选为目标；抵消 = 对该目标不生效（【闪】抵消【杀】）；取消 = 不再是此牌的目标（【谦逊】）。
- 受到伤害 ≠ 失去体力：后者无来源、不结算、不触发受伤类技能。
- 濒死：进入濒死状态时（【补益】）→ 处于濒死状态时，从当前回合角色起逆时针依次响应，可对濒死者用【桃】或由其自己用【酒】（【涅槃】【不屈】），体力回至 ≥1 即存活，否则死亡；同一时刻只有一人濒死。
- 死亡：体力上限减为 0 者直接死亡，不能被挽救；杀死 = 目标因某来源的伤害进入濒死且未被挽救。
- 连环（横置／重置）：**横置** = 将武将牌横放，令该角色进入连环状态（此角色称"横置角色"）；**重置** = 将横置的武将牌摆正，令该角色解除连环状态。
  - 连环状态只有"是"与"否"两种：已是横置角色的不能再被横置，重置对未横置的角色也不产生效果。

### 技能

| 类别 | 含义 |
| --- | --- |
| 状态类技能 | 无发动时机，能产生影响就必须产生（【空城】【智迟】） |
| 锁定技 | 能发动必须发动，与优先级无关（看有无"可以"二字） |
| 限定技 | 一局一次（【涅槃】） |
| 觉醒技 | 到时机必须发动，一局一次（【魂姿】） |
| 主公技 | 仅主公有效（【激将】） |
| 持恒技 | 不能被其他技能失效 |

- 技能六要素：发动角色、条件、时机、消耗、目标、效果。
- 觉醒技默认附带"锁定技"标签（同时视作附带"限定技"标签）：故其既强制发动、又一局一次，且不受"令非锁定技失效"的效果（【铁骑】【义绝】）影响。
- 主公技可以被非主公角色获得：如袁术因【伪帝】拥有主公的主公技。
- 可以／须／任意数量／选择一项：有选择权／强制／可为 0／多选一。
  - 多选项技能：只有条件满足、能够执行的选项才能选 —— 无手牌的角色面对【雌雄双股剑】只能选"令你摸一张牌"。
- 角色失去技能或死亡时：状态类效果继续，与其无关的延时效果继续（【鸡肋】），与其本人绑定的效果消失（【完杀】【狂风】）。

## 四、游戏牌

| 类别 | 细分 | 举例 |
| --- | --- | --- |
| 基本牌 | 普通【杀】、火【杀】、雷【杀】 | 【杀】【闪】【桃】【酒】 |
| 锦囊牌 | 普通锦囊牌、延时锦囊牌、伤害类锦囊牌 | 【无中生有】／【乐不思蜀】／【决斗】 |
| 装备牌 | 武器、防具、【+1坐骑】、【-1坐骑】、宝物 | 【青釭剑】【八卦阵】【的卢】【木牛流马】 |

- 基本牌的【杀】分为普通【杀】、火【杀】、雷【杀】三种；在涉及"基本牌"类别的技能中，这三张【杀】各自独立结算。
- 延时类锦囊：结算完毕，牌留在判定区。待该角色的判定阶段按置入顺序从后往前依次进行判定（无使用者）。判定区里已有同名牌者不是使用该牌的合法目标。

### 基本牌的牌面信息

**【杀】** 出牌阶段限一次，对你攻击范围内的一名其他角色使用。你对其造成1点伤害。
**【火杀】** 出牌阶段限一次，对你攻击范围内的一名其他角色使用。你对其造成1点火焰伤害。
**【雷杀】** 出牌阶段限一次，对你攻击范围内的一名其他角色使用。你对其造成1点雷电伤害。
**【闪】** 以你为目标的【杀】生效前使用，抵消此【杀】；
**【桃】** 出牌阶段回复已受伤的你1点体力或令一名处于濒死状态的角色回复1点体力。
**【酒】** 出牌阶段令你本回合使用的下一张【杀】伤害+1（你以此法使用的酒，每回合限一次）或令处于濒死状态的你回复1点体力。

## 五、扩展机制

- 隐匿技：晋势力武将的技能标签 —— 拥有者开局以"隐匿"状态出场（扣置真正的武将牌，无体力值，性别为男），受到伤害或失去体力而扣减体力、或自己的回合开始时，亮出真正的武将牌，称为"登场"；隐匿技于登场后发动，且发动时不声明、直接执行效果。
- 使命技：一种特殊的技能。拥有成功/失败的条件以及对应的奖励/惩罚；使命技成功或失败后，对应的使命技失效。
- 韵律技：韵律技是一种特殊的转换技，分为“平”和“仄”两种状态。在游戏开始时，韵律技均处于“平”状态;当满足“转韵”条件后,韵律技会转换到另一个状态,且重置技能发动次数。
- 奋武技：奋武技是一种特殊的技能,奋武技使用次数为本轮你造成和受到的伤害值+1,至多为5。
- 宗族枝：一种与宗族相关的特殊技能，拥有这类枝能的武将称为宗族武将、宗族技相同的武将即为同族武将。
- 蓄力技：蓄力技是一种特殊的技能,描述中含有“蓄力技(X/Y)”X为游戏开始时可获得的初始蓄力标记数量;Y为你可积累的蓄力标记上限。发动蓄力技需要根据技能条件消耗蓄力标记。当一名角色同时拥有多个蓄力技时,所有蓄力技消耗同样的蓄力标记。X和Y进行分别相加后生效。
- 连招技："连招技（A+B）" —— 你使用 B 类别的牌时，若你使用的上一张牌属于类别 A（且该牌未发动过此技能），则你可以发动技能的后续效果。
- 谋略值：谋略值是一种通过特定方式累计谋略标记,并可以消耗谋略标记使用虚拟牌的技能。谋略值的上限为5点，拥有谋略值的角色拥有技能“妙计”：每回合限一次，你可以消耗谋略值。视为使用对应的牌:1点【过河拆桥】，3点【无懈可击】，3点【无中生有】
- 智囊牌：无中生有、无懈可击、过河拆桥。
- 护甲：受到伤害时先扣护甲，护甲不足的部分再扣体力。可抵伤害、可触发受伤类技能，不抵体力流失，不加手牌上限；上限为 5，并入致命伤害的计算。
- 背水：技能的特殊选项 —— 先依次执行各选项，再执行背水的后果；发动技能时，若无法执行背水的后果，则无法选择背水。
- 乘势：多分支效果中，若各分支的触发条件均满足，则额外触发。
- 追思：一些技能可以令一名角色进行追思，即其获得另一面满足条件的角色的武将牌上除主公技以外的技能，然后失去其原本武将牌上的所有技能。不能追思已被追思过的角色。
- 仁区：场上额外且独立的区域，不属于任何角色；至多置入 6 张"仁"牌，超出时最早置入的那张置入弃牌堆。
- 谋弈：发起者和目标角色需分别从多个选项中选择一项。若目标角色未选择与发起者相对应的选项，则发起者“谋奕成功”，否则发起者“谋奕失败”。
- 冰杀：基本牌，使用规则同普通【杀】；造成伤害时，你可防止此伤害，改为依次弃置目标角色的两张牌。
- 刺杀：基本牌，使用规则同普通【杀】；目标使用【闪】抵消此【杀】时，若其有手牌则须弃置一张手牌，否则此【杀】依然造成伤害。
- 议事：没有手牌的角色不能参加议事；议事至少要有两名角色参与；与投票类似，所有参与议事的角色同时展示一张手牌，若议事展示手牌中红色牌多于黑色牌，则执行技能中红色的后续效果，若黑色牌多于红色牌,贝执行技能中黑色的后续效果；若红色牌黑色牌数量相等，则不执行后经效果。
- 意见：议事的衍生概念，在一次议事中展示手牌颜色相同的角色即为意见相同。展示手牌颜色不同的角色相互视为意见不同。
- 变更势力：你将势力变更至与当前势力不同的任意势力。
- 势力技和双势力武将：双势力武将在登场时需要选择其武将牌左上角的一个势力作为自己的初始势力。只有你当前的势方相对应的势力技生效。
- 【影】：均为黑桃A的基本牌，没有默认使用或打出方法。游戏外无限量供应当【影】进入弃牌堆后改为移出游戏；一名角色获得【影】默认从游戏外获得。
- 蓄谋：你将一张手牌扣置于你的判定区内；你判定区里的蓄谋牌对且仅对你可见；你的判定阶段开始时，若你的判定区内有蓄谋牌，你按置入顺序（后置入的先处理）依次处理蓄谋牌：1.使用这张蓄谋牌;2.将你判定区内所有蓄谋牌置入弃牌堆。
  - 蓄谋牌满足以下规则:
    1.当你使用蓄谋牌后，本阶段不能再使用牌名与之相同的蓄谋牌。
    2.每次蓄谋仅能扣置一张牌。
    3.蓄谋牌处于你的判定区内，此类牌可以被弃置、获得、移动等。
- 逐鹿：逐鹿即共同拼点.是拼点的一种子类别；进行拼点时,拼点牌点数唯一最大的角色为拼点赢的角色,其余角色为没赢的角色;若没有拼点牌点数唯一最大的角色 则所有角色都没赢。
